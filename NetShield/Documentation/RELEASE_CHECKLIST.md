- Compile in Unity 2021.3 LTS, 2022.3 LTS and Unity 6; resolve all warnings and errors.
- Test clean installation and upgrade from 2.0.1 with obsolete files removed; preserve scene references, settings and cache.
- Verify Config, API and Third-Party open immediately and local checks work without an acceptance resource.
- Test source switches, IPv4/IPv6, whitelist, custom imports, offline behavior, database refresh, backups and profiles.
- Test manager actions, events, delay, cooldown, periodic monitoring and persistence.
- Test intended player platforms, Mono and IL2CPP. No networking integrations are included.
- Verify third-party source licenses and service terms. Do not publish downloaded databases or private custom lists without the necessary rights.

- Disclose supported versions and limitations accurately. AI assisted research, implementation and documentation.

Unity compilation and runtime testing have not been performed in the package creation environment.
